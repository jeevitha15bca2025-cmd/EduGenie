# 7. Project Documentation

## Project Title

EduGenie – Generative AI Based Personalized Learning Assistant

## Abstract

EduGenie is a Generative AI-based educational web application designed to assist students in learning different concepts in a simple and personalized manner.

The application allows learners to enter a topic, question or educational content and receive AI-generated explanations and learning assistance.

## Technologies Used

### Frontend

- HTML
- CSS
- JavaScript

### Backend

- Python
- FastAPI
- Uvicorn

### Artificial Intelligence

- Google Gemini API
- google-genai

### Configuration

- python-dotenv
- .env

### Testing

- pytest

## Main Features

### Question Answering

Students can ask questions and receive AI-generated answers.

### Topic Explanation

Students can request explanations according to their learning level.

### Quiz Generation

The system can generate quiz questions from educational content.

### Text Summarization

The system can summarize longer educational content.

### Learning Recommendations

The system can provide learning recommendations based on topic, level and duration.

## Advantages

1. AI-powered learning
2. Personalized explanations
3. Multiple learning activities
4. Interactive interface
5. Modular architecture
6. Expandability

## Limitations

1. Gemini functionality depends on API availability.
2. Internet connectivity is required for cloud-based Gemini generation.
3. API usage may be subject to model and account limits.
4. AI-generated content should be reviewed for accuracy.
5. Local AI models may require significant system resources.
6. The application is an educational assistant rather than a complete learning management system.

## Future Enhancements

Possible future enhancements include:

- Student Login

- Quiz Score Tracking
- Student Dashboard

- Continuous AI Tutor

## Security

API keys should not be stored directly in source code.

The project uses environment variables to store the Gemini API key.

The .env file should not be uploaded to GitHub.

## Conclusion

EduGenie demonstrates how Generative AI can be integrated into an educational web application to provide interactive learning assistance.

The system combines Python, FastAPI, JavaScript, HTML/CSS and Google Gemini to create an AI-powered educational assistant.
