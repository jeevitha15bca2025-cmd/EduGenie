# 1. Brainstorming & Ideation

## Project Name
EduGenie – Generative AI Based Personalized Learning Assistant

## Introduction

EduGenie was proposed as a Generative AI-based educational web application designed to help students understand educational concepts in a simple and personalized manner.

The initial idea was to develop an AI-powered learning assistant that could provide students with immediate educational support instead of depending only on traditional learning methods.

## Problem Identified

During the brainstorming stage, the following problems were identified:

1. Students may find complex explanations difficult to understand.
2. Students may require immediate answers to their questions.
3. Preparing practice quizzes manually can take considerable time.
4. Long educational content can be difficult to understand.
5. Students may require personalized learning paths.
6. Different students may require explanations according to their learning level.

## Proposed Idea

The proposed solution was to create a web-based AI learning assistant where students can:

- Ask questions.
- Request explanations of topics.
- Generate quizzes.
- Summarize educational content.
- Get personalized learning recommendations.

## Main Features Identified

The brainstorming process resulted in five major learning activities:

1. Question and Answer
2. Topic Explanation
3. Quiz Generation
4. Text Summarization
5. Personalized Learning Recommendations

## Target Users

EduGenie is intended to support:

- School students
- College students
- Beginners learning programming
- Self-learners
- Students preparing for revision
- Students practicing quizzes

## Technology Idea

The initial technology concept was to build:

- Frontend: HTML, CSS and JavaScript
- Backend: Python and FastAPI
- AI: Google Gemini API
- Server: Uvicorn
- Testing: pytest

## Expected Outcome

The expected outcome was an interactive educational web application capable of accepting student input and generating useful educational content based on the selected learning activity and learning level.
