# 6. Project Testing

## Project Name
EduGenie – Generative AI Educational Assistant

## 1. Testing Overview

Testing is performed to ensure that EduGenie works correctly, reliably, and according to the specified requirements.

## 2. Types of Testing

### Unit Testing

Individual functions and modules are tested independently.

### Integration Testing

Different components are tested together to ensure proper communication.

### System Testing

The complete EduGenie application is tested as a single system.

### User Acceptance Testing

The application is evaluated from the user's perspective to ensure that it meets expected requirements.

## 3. Sample Test Cases

| Test ID | Test Case | Expected Result |
|---|---|---|
| TC01 | Register with valid details | User account created |
| TC02 | Register with existing email | Error message displayed |
| TC03 | Login with valid credentials | User successfully logged in |
| TC04 | Login with invalid credentials | Login error displayed |
| TC05 | Submit valid AI question | AI response generated |
| TC06 | Submit empty question | Validation message displayed |
| TC07 | Generate educational content | Relevant content generated |
| TC08 | Logout | User session terminated |
| TC09 | Invalid API request | Appropriate error returned |
| TC10 | Database operation | Data stored/retrieved correctly |

## 4. Testing Objectives

- Verify application functionality
- Identify defects
- Verify AI integration
- Validate user authentication
- Test API communication
- Verify database operations
- Ensure usability

## 5. Bug Tracking

Identified bugs are recorded and classified based on severity.

Severity levels:

- Critical
- High
- Medium
- Low

## 6. Test Results

Testing results are documented to verify whether each feature meets its expected behavior.

## 7. Conclusion

Testing helps ensure that EduGenie provides a reliable and user-friendly educational experience.
